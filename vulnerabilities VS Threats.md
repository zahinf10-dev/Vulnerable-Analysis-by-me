#  Threat VS Vulnerability by ME 

| No | Scenario | Category | Reasoning |
|----|----------|----------|-----------|
| 1 | An unidentified user attempts to brute-force a legacy FTP server with a guessable administrative password. | Threat | Brute-force — A deliberate, direct attempt to crack authentication using dictionary or automated guessing techniques. |
| 2 | A corporate mobile device policy permits users to install applications from unverified third-party sources. | Vulnerability | Insecure Configuration — A policy-based flaw that opens the system to side-loading unvetted, potentially malicious software. |
| 3 | A third-party SaaS provider has a critical, unpatched data-at-rest encryption flaw in their client interface. | Vulnerability | Third-Party Risk — The reliance on an external service with an unaddressed, critical technical defect. |
| 4 | Sophisticated state-sponsored attackers are attempting to pivot from a smaller target to the main corporate network. | Threat | Advanced Persistent Threat (APT) — A multi-stage, determined attack by a skilled entity. |
| 5 | Internal training programs for identifying and reporting suspected social engineering are not mandatory. | Vulnerability | Weak Security Culture — The absence of proper human-element training creates an organizational weak point. |
| 6 | Multiple, unpatched IoT sensors are found to be directly accessible from the public internet. | Vulnerability | Attack Surface Exposure — Misconfigured and unmanaged edge devices create easily accessible entry points. |
| 7 | A key-logging malware is discovered on a sensitive workstation in the finance department, stealing transaction logs. | Threat | Spyware — A malware attack designed to collect sensitive data surreptitiously from a specific host. |
| 8 | The main database uses an older version of software with a publicly known, critical flaw (CVE). | Vulnerability | Known Flaw — The continued use of software with public knowledge of its critical security bugs. |
| 9 | An ex-employee retains their access credentials to the CRM system long after their departure. | Threat | Credential Abuse — The deliberate misuse of legitimate credentials by a former insider. |
| 10 | A web application has no Cross-Site Request Forgery (CSRF) tokens on state-changing forms. | Threat | Application Logic Flaw — Exploitation of missing CSRF protection to execute unauthorized actions on state-changing forms. |
